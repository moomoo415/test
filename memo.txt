git 버전 확인
git --version
# 2.50.1

프로젝트 디렉토리에 로컬 저장소 생성
git init
# Initialized empty Git repository in /Users/jasper_k/Desktop/Moomoo/git/.git/ 
# 로컬저장소를 생성했다는 뜻 (command + shift + .) 하면 숨김 [.git] 파일이 생긴 것을 알 수 있다.

git 버전 관리할 파일을 선택 : state에 올림
git add test.py

버전 만들기 : 커밋
git commit -m "test.py를 커밋"

# 깃에 이메일 및 이름 저장 ( ㅂ면경시에도 동일하게쓸 수 있다.)
git config --global user.email "이메일주소"
git config --global user.name "이름"

로그 확인
git log

# 폴더의 파일 전체를 stage에 올리는 것
git add .  


로컬 저장소에서 github 원격 저장소 주소를 등록
git remote add origin https://github.com/moomoo415/test.git

생성한 커밋들을 github에 전송(푸시)
git push -u origin main

git remote add origin https://github.com/moomoo415/test.git
git branch -M main
git push -u origin main


Fork
하나의 저장소를 다른 계정으로 복사
git 명령어가 아님(github 기능)
> 다른 사람의 github 계정 저장소에서 fork를 눌러 내 계정 저장소로 복사

원격 저장소에서 변경된 사항을 가졍괴
git pull origin(가져와서 merge)
git fetch origin(가져오기만)


.gitignore
git이 추적하지 않아야 할 파일을 지정하는 파일
